# HorizonProtocol

Horizon 生态的通信协议契约仓库：契约正文、登记表与版本历史。本仓库是协议的唯一真理源，不含跨端共享代码；实现仓库发现契约问题时记录并报告，不得私改。

- 当前协议版本：**1.0.0**（`HELLO.v` = 1），范围为 Phase 1：账号域、节点注册、基础队伍。
- 覆盖两个平面：App（默认 44444/TCP，`HorizonMobile` 接入）与节点（默认 44443/TCP，`HorizonModServer` 接入）。
- 设计基线：机制沿用 AEMobile 3.0.0 已验证实现，与旧协议的差异见 `契约.md` §11。
